# retail-store-sales-analysis

Built an end-to-end retail sales analysis project using Excel, MySQL, and Power BI.

- Analyzed 300 sales records from 2025.
- Used Excel formulas and PivotTables for data analysis.
- Wrote SQL queries to analyze revenue, profit, regions, categories, and monthly trends.
- Developed an interactive Power BI dashboard with KPIs, charts, and slicers.

**Tools:** Excel, MySQL, Power BI, SQL
